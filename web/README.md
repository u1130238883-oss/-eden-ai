# 九型十二宮 網站

會員制的網站版：今日免費，命盤／運程／合盤要會員。
收款走你自己的微信與支付寶收款碼，你在後台按一下「確認收款」就開通。

## 語言

一個網站包含四種語言，右上角隨時可以切：**繁體中文、English、Español、Italiano**。

和 App 不一樣 —— App 是一個版本兩種語言（要裝兩支），網站是**一個網址四種語言**，
不必分開架。第一次進來的人會照他手機或電腦的語言自動顯示，之後以他自己選的為準。

所有內容都跟著換：宮位名稱、含義、九型人格的完整說明、付款頁的說明文字，
連錯誤訊息都會跟著語言走。後台（`/admin`）只有你會用，維持中文。

## 先看懂這一件事：為什麼要你按一下

個人的微信／支付寶收款碼**沒有辦法讓網站自動知道誰付了錢** —— 個人收款碼不會
回報任何東西給網站，這是微信和支付寶的設計，不是這個網站做不到。
要全自動，必須申請**商戶號**（需要營業執照），那是另一件事。

所以流程是這樣：

1. 客人選方案，網站給他一組六位的**付款編號**，例如 `WXEUR9`
2. 客人掃你的收款碼付錢，**在備註欄填那組編號**
3. 你在微信／支付寶看到入帳，備註就是那組編號
4. 你打開後台，對一下金額，按「確認收款」
5. 客人那邊按「我付好了」就開通了

一次大概十秒。等你以後有商戶號，再改成全自動。

另外還有**啟用碼**：後台可以產生像 `NT-PWLG-VSUR-JZNN` 這樣的碼，
直接在微信上發給人，對方在網站上輸入就開通。適合熟客或線下收錢。

## 跑起來

不需要安裝任何套件，只要有 Python 3.8 以上：

```bash
export NT_ADMIN_PASSWORD='換成你自己的密碼'
python3 web/server/app.py
```

打開 http://localhost:8000 ，後台在 http://localhost:8000/admin

### 環境變數

| 變數 | 用途 | 預設 |
|---|---|---|
| `NT_ADMIN_PASSWORD` | 後台密碼。**沒設的話後台會打不開** | 無 |
| `PORT` | 監聽的埠 | `8000` |
| `NT_DB` | 資料庫檔案位置 | `web/data/nt.sqlite3` |

## 放你自己的收款碼

把兩張圖放成這兩個檔名就好，網站會自動抓：

```
web/static/pay/wechat.png     微信收款碼
web/static/pay/alipay.png     支付寶收款碼
```

還沒放的時候，網站會顯示一張「還沒放收款碼」的佔位圖，不會壞掉。

**這兩張圖沒有放進 git**（`.gitignore` 擋掉了），是故意的 —— 收款碼是你的錢，
不應該跟著程式碼到處跑。你在自己的伺服器上放就好。

## 放到網路上

這個程式就是一個普通的 Python 程式，聽 `PORT`，哪裡都能跑。

**最省事的做法**（免費方案就夠用）：Render、Railway、Fly.io 之類的服務，
建一個 Web Service，指到這個 repo，啟動指令填：

```
python3 web/server/app.py
```

然後在該平台的設定裡加上 `NT_ADMIN_PASSWORD`。

**要注意資料庫**：`nt.sqlite3` 存的是誰是會員、到期日、訂單。
很多免費方案的硬碟是「每次重新部署就清空」的，那樣會員資料會不見。
所以要**掛一個持久磁碟**，把 `NT_DB` 指到那個磁碟上，例如 `/data/nt.sqlite3`。
這一步不要省，不然客人付了錢隔天會員會消失。

**一定要用 HTTPS**（平台通常自動給）。

## 資料

只存這些：一組隨機識別碼、會員到期時間、訂單編號與金額、啟用碼。
**不存姓名、不存 email、不存生日** —— 生日只在算的那一瞬間經過，不落地。

## 演算法在哪

在 `server/engine.py`，**只在伺服器上跑**。瀏覽器拿到的永遠是算好的結果，
拿不到規則。`tools/test_web.py` 裡有一項專門檢查這件事：
確認前端的 JavaScript 裡完全沒有演算法的痕跡。

## 測試

```bash
python3 tools/verify_web_engine.py   # 算出來的和 App 一模一樣嗎
python3 tools/test_web.py            # 整條流程：付款、鎖、啟用碼、後台
```
