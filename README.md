# Eden AI v0.1

iPhone-first PWA prototype for an adult romantic AI companion.

## Included
- iPhone-friendly UI
- 3 adult fictional characters
- Local chat history via localStorage
- Basic relationship state
- Chinese/English/Italian-friendly interface
- Add-to-Home-Screen PWA manifest

## Important
This v0.1 is a client-only prototype. It does not connect to an LLM API yet, so its replies are local demo replies.

For real AI responses, a backend/model endpoint must be added. Do not put secret API keys in frontend JavaScript.

GitHub Pages can publish static HTML/CSS/JavaScript from a repository.
