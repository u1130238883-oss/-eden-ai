# 上架 Google Play 與收款（安卓版）

安卓版和 iOS 版最大的差別，就是**安卓可以不透過商店發行**。
這一點直接決定了你能不能收微信／支付寶。

---

## 一、先看懂這張表

| | Google Play 版 | 直連版（自己發 APK） |
|---|---|---|
| 怎麼發給用戶 | Google Play 商店 | 你的網站、二維碼、雲端硬碟、微信傳檔 |
| 收款方式 | **只能**用 Google Play 帳單 | **任何方式**，包括微信支付、支付寶 |
| 錢進到哪裡 | Google 的付款設定檔 → 銀行帳戶 | 直接進你的微信／支付寶 |
| 抽成 | 訂閱第一年 15%（Google 已對訂閱全面採 15%） | 0 |
| 開發者費用 | 一次性 US$25 | 0 |
| 用戶信任度 | 高 | 低（要手動允許「安裝未知來源」） |

**結論**：你說「沒有國際通用銀行卡」的問題，在安卓上是**有解的** ——
走直連版，微信／支付寶收款完全合法，因為 Google 的付款政策只管在 Play 上架的 App。

所以我一次做了四個版本，你可以兩條路同時走。

---

## 二、四個 APK 是什麼

| 檔名 | 語言 | 發行管道 | 套件名 |
|---|---|---|---|
| `NineTwelve-zh-en-play.apk` | 繁中／英文 | Google Play | `com.ninetwelve.fortune` |
| `NueveYDoce-es-it-play.apk` | 西班牙文／義大利文 | Google Play | `com.ninetwelve.fortune.latin` |
| `NineTwelve-zh-en-direct.apk` | 繁中／英文 | 自己發 | `com.ninetwelve.fortune.direct` |
| `NueveYDoce-es-it-direct.apk` | 西班牙文／義大利文 | 自己發 | `com.ninetwelve.fortune.latin.direct` |

四個套件名都不一樣，所以可以同時裝在同一支手機上，互不影響。

**主畫面上的名稱會跟著手機的系統語言換**：
中文手機顯示「九型十二宮」，英文手機顯示「Nine & Twelve」，
西班牙文手機顯示「Nueve y Doce」，義大利文手機顯示「Nove e Dodici」。

## 三、直連版：微信／支付寶收款

### 運作方式

1. 用戶點開命盤／運程／合盤，看到付款頁，上面有你的微信與支付寶收款碼。
2. 頁面上還有一組**裝置碼**（例如 `K7QX4M2Z`），是這台手機獨有的。
3. 用戶付款，把裝置碼傳給你。
4. 你產生一組**啟用碼**回給他。
5. 他輸入啟用碼，App 當場解鎖，不需要連網。

啟用碼綁定裝置碼，換一台手機就失效，所以不能互相轉傳。

### 上架前你要改兩個東西

**1. 換成你自己的收款碼**

把你的微信與支付寶收款碼存成 PNG，覆蓋掉這兩個檔案：

```
android/app/src/direct/res/drawable-nodpi/pay_wechat.png
android/app/src/direct/res/drawable-nodpi/pay_alipay.png
```

現在裡面是明顯的佔位圖（灰色方塊，寫著 REPLACE WITH YOUR），
沒換掉的話用戶會看到那張佔位圖。

> 我沒有把你傳給我的收款碼放進去，因為這個專案在 GitHub 上，
> 收款碼放進版控等於公開。你自己換，換完再建置。

**2. 換掉驗證金鑰**

打開 `android/gradle.properties`，把這一行改成只有你知道的一串字：

```
ninetwelve.activationSecret=CHANGE-ME-BEFORE-RELEASE
```

改完之後**先建置 APK，再用同一組金鑰產啟用碼**，兩邊必須一致。

### 產生啟用碼

```bash
export NINETWELVE_SECRET='你剛才設的那串字'
python3 tools/make_activation_code.py K7QX4M2Z 1
```

輸出：

```
裝置碼　：K7QX4M2Z
有效期至：2026-09-19（1 個月）
啟用碼　：20260919-P4WT9BXK
```

最後那個數字是月數，要賣半年就寫 `6`。

### 這個做法的限度

金鑰是編進 APK 裡的，會反編譯的人可以把它挖出來自己發碼。
對這個規模的軟體夠用，但它不是防不破的。
真的要防，得改成連你自己的伺服器驗證 —— 那要另外租一台機器，是另一件工程。

## 四、Google Play 版：上架步驟

### 第 1 步：註冊開發者帳號

<https://play.google.com/console/signup> —— **一次性 US$25**，不像蘋果每年 US$99。

個人帳號需要**身分驗證**（證件 + 地址），約一到數個工作天。

> ⚠️ **2023 年 11 月之後開的個人帳號**，要先做「封閉測試」：
> 至少 **12 位測試者、連續 14 天**，才能申請正式發佈。
> 這一步跑不掉，建議一註冊就先把測試者找齊（親友的 Google 帳號就行）。

### 第 2 步：建立兩個 App

| | 中英版 | 西義版 |
|---|---|---|
| 套件名 | `com.ninetwelve.fortune` | `com.ninetwelve.fortune.latin` |
| 名稱 | 九型十二宮 | Nueve y Doce |
| 預設語言 | 繁體中文 | 西班牙文 |

### 第 3 步：建立訂閱商品

每個 App 各建一個**訂閱**，商品編號必須與程式碼一致：

```
pro_monthly
```

（兩個 App 的商品編號可以一樣，因為它們是不同的 App。）

計費週期選 **1 個月**。定價設定裡選「管理各國價格」：

| 地區 | 價格 |
|---|---|
| 歐元區 | €10.00 |
| 美國 | US$10.00 |
| 英國 | £10.00 |
| 中國 | ¥80.00 |

Google Play 不像蘋果有固定價位表，**可以直接填 10 和 80**，你原本想的價格能照定。

### 第 4 步：做一把上傳金鑰

```bash
keytool -genkeypair -v -keystore upload.jks \
  -alias upload -keyalg RSA -keysize 2048 -validity 10000
```

**這個檔案和密碼要收好，弄丟就沒辦法再更新這個 App。**

然後在 `android/keystore.properties` 寫（這個檔案已被 .gitignore 排除，不會進版控）：

```
storeFile=/絕對路徑/upload.jks
storePassword=你的密碼
keyAlias=upload
keyPassword=你的密碼
```

建置上傳用的 AAB：

```bash
cd android
gradle bundleCjkPlayRelease bundleLatinPlayRelease
```

產出在 `android/app/build/outputs/bundle/*/`。

> 也可以讓 GitHub 幫你建：把金鑰設成 repo 的 secret
> （`ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`、
> `ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`），
> CI 就會自動產出 AAB。`ANDROID_KEYSTORE_BASE64` 用 `base64 -i upload.jks` 取得。

**Play 會拒絕用 debug 金鑰簽的檔案**，所以我給你的那四個 APK 只能自己測試與直連發佈，
不能拿去上傳 Play。

### 第 5 步：送審

要準備：截圖（手機至少 2 張）、512×512 圖示、1024×500 橫幅、
簡短說明、完整說明、隱私政策網址、內容分級問卷、資料安全表單。

**資料安全表單**這一份可以照實填得很乾淨：這個 App 不連網、不收集任何資料、
不要任何權限，生日只存在手機本機。

## 五、Google Play 的錢怎麼進到你手上

Play Console 要你建立**付款設定檔**，需要：

- 一個**銀行帳戶**
- 稅務資料

**支付寶和微信不是銀行帳戶，Google 不接受**，這一點和蘋果一樣。

而且有個比蘋果更麻煩的地方：**Google Play 的「可收款國家／地區」清單不包含中國大陸**。
也就是說，你很可能**沒辦法用中國的身分與中國銀行帳戶註冊 Play 的付款設定檔**。
這一條請你註冊時自己在 Play Console 裡確認一次（清單會變），別聽我一面之詞。

如果確實不行，你在 Google Play 上就只能：

- 先把 App 免費上架（不收費也能上架，累積用戶與評價），
- 收費走**直連版**（微信／支付寶），
- 等以後有辦法辦到符合條件的銀行帳戶，再把 Play 的訂閱打開。

**這正是我把直連版做出來的原因。** 對你現在的處境（人在義大利、沒居留、沒國際銀行卡），
直連版是唯一能真的收到錢的路。

## 六、怎麼把直連版發給用戶

1. 把 `NineTwelve-zh-en-direct.apk` 放到任何能下載的地方
   （你的網站、Google Drive、微信公眾號、甚至直接微信傳檔）。
2. 告訴用戶：下載後點開，Android 會問「要允許從這個來源安裝嗎」，按允許。
3. 用戶第一次開啟就能用「今日」，要看命盤／運程／合盤時會看到你的收款碼。

安裝未知來源的 App 是安卓的正常功能，不是破解，也不違反任何規定。

## 七、常用指令

```bash
cd android

# 四個 APK 一次建好（可直接安裝）
gradle assembleCjkPlayDebug assembleLatinPlayDebug \
       assembleCjkDirectDebug assembleLatinDirectDebug

# 單元測試（和 iOS 版是同一組案例，算法必須一模一樣）
gradle testCjkPlayDebugUnitTest

# Google Play 上傳用的 AAB（需要 keystore.properties）
gradle bundleCjkPlayRelease bundleLatinPlayRelease
```

產生啟用碼：

```bash
export NINETWELVE_SECRET='你的金鑰'
python3 tools/make_activation_code.py <裝置碼> <月數>
```
