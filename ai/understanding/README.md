# 中文理解訓練（2026-10-23）

## 題目

- `gen.py` → `Fixtures/understanding_questions.json`：**50,000 題**，每題附標準答案：
  - **route**：上網查（web）／用命盤算（fortune）／說心情、要安慰（feeling）／聊天（chat）
  - **want**：上網要什麼樣的答案（數字、人、地點、時間、定義、原因、名單、比較、做法、作品內容……）
  - **subject**：要查的主題
  題目由句型 × 真實名稱組成，再加上口語的包裝（「請問…」「我想知道…」「你知道…嗎」「欸…」「所以…」「…呢」、有沒有問號），
  並刻意放進陷阱：書名、片名、名詞裡有情緒字（少年維特的**煩惱**、**悲傷**逆流成河、**孤獨**的美食家、**憂鬱**症、**情緒**勒索）。
- `holdout.py` → `Fixtures/understanding_holdout.json`：**4,110 題沒看過的問法和名稱**（訓練題裡沒有），
  檢查是真的理解、不是背句型。
- 測試：`UnderstandingCorpusTests`（平常跑前 6,000 題＋全部驗證題；`NINESUN_UNDERSTAND_ALL=1` 跑全部 50,000 題）。

## 錯在哪裡、人會怎麼想、怎麼改

### 1. 開頭的客套話讓它認不出問題
- 錯：「所以什麼是人工智慧」「好奇誰發明了火藥」「可以告訴我冥想有哪些好處嗎」→ 認成一般閒聊。
- 人的步驟：先把「請問、我想知道、所以、那、欸、好奇、想問一下、可以告訴我…嗎、你知道…嗎」拿掉，再看剩下的才是問題。
- 改：`Understanding.clean`。「那」只有當連接詞才拿掉——「那些年，我們一起追的女孩」「那個人」是名稱的一部分。
  `EchoEngine.tidy`：開頭的「嘿、欸、喂」、結尾的「～、!、。」只是口氣。

### 2. 名稱、名詞裡的情緒字被當成心情
- 錯：「少年維特的煩惱這本書講了什麼」「解釋一下憂鬱症」「快樂王子講了什麼」→ 回「先深呼吸一下」。
- 人的步驟：問「**是誰**在難過？」——說話的人自己（我好、很、最近、到睡不著…）才是心情；
  在問一個東西（是什麼、講了什麼、作者、劇情、解釋）就是知識題，就算名稱裡有「煩惱」。
- 改：`EchoEngine.selfFeeling`（心情要有「我／好／很／一直…＋情緒」或「情緒＋到」），`asksAboutWork`（問作品）。
  想解決它（「如何緩解焦慮」「改善失眠的方法」）是要方法，上網查；「我好焦慮，怎麼辦」才是要安慰。

### 3. 主題字把一般問題帶去算命
- 錯：「租房和買房的差別」→ 4宮（因為「房」）；「出國有什麼要注意的」→ 9宮；「共享經濟是什麼」→ 錢財；
  「羅浮宮位於哪裡」→ 命宮（「羅浮**宮位**於」裡有「宮位」）。
- 人的步驟：先問「這是在問**我的命**，還是在問**世界上的事**？」——有運勢、命盤、流年、八字、「我會不會／我什麼時候會／我適合嗎」
  才是問命；其他的再看是什麼題型。
- 改：`EchoEngine.fortuneAsk`（「宮位」後面接「於」不算）、`worldQuestion`（放在安慰、算命之前判斷）。
  命理的術語（化忌、四化、日主、喜用神）用自己的資料庫；問自己的優點、九型（「我的優點是什麼」）由命盤回答。

### 4. 問法沒學過
- 錯：「X有什麼要注意的」→ 名單；「X有哪些好處」→ 名單；「X的劇情是什麼」→ 名詞解釋；「誰寫了X」「X是為什麼」「X是幾年發生的」「教我X」
  「A還是B比較好」「X的Y有哪些」都認不出來。
- 改：補上這些句型（`Understanding.frame`）。

### 5. 背句型不是理解（沒看過的題只有 66%）
- 錯：「誰是追風箏的孩子的作者」「有沒有什麼方法可以準備多益」「量子力學的意思」「想準備多益要從哪裡開始」都不會。
- 人的步驟：**先找關鍵字，不管它在句子的哪裡**——「誰」→ 要人名；「哪一年、何時」→ 時間；「哪裡、哪個城市」→ 地點；
  「方法、技巧、從哪裡開始、怎樣才能」→ 做法；「意思、解釋」→ 定義；「大綱、在說什麼」→ 作品內容；
  **再把這些問句的字拿掉，剩下的就是主題**（「誰是｜追風箏的孩子｜的作者」）。
  順序有意義：「在哪一年」要先當成時間，不能被「在哪」搶走。
- 改：`Understanding.general`（關鍵字分組 + 拿掉問句的字找主題）。沒看過的題從 66.45% → 100%。

### 6. 其他
- 「幫我查一下原子習慣是誰寫的」：以前拆成關鍵字「原子習慣 寫的」，丟掉「是誰」就不知道要找人名 → 保留整個問題。
- 「那些年，我們一起追的女孩」：「那些」被當成在指上一題 → 片名不是指代。
- 「我想提升口才該怎麼做」：「提升」被九型人格接走 → 有具體要提升的東西就是一般做法題。
- 「做簡報」被當成做菜，只查「簡報」→「做」只有後面是食物才是做菜。
- 「說服別人」被「所以說」吃掉一個「說」→ 開頭只拿掉「所以」。
- 「冷戰的意思」：「冷戰」被當成感情冷戰 → 問「意思」就是知識題。
- 心情詞補上「失落、沮喪、壓力超大、沒用、自卑」（`ai/solace.py`）。

## 之後要加新的問法時
1. 先在 `gen.py`（訓練）或 `holdout.py`（驗證）加題目和標準答案。
2. 跑 `NINESUN_UNDERSTAND_ALL=1 NINESUN_UNDERSTAND_OUT=/tmp/u swift test -c release -Xswiftc -enable-testing --filter UnderstandingCorpusTests`，
   看 `/tmp/u.*.txt` 裡錯的題目分組。
3. 想「人會怎麼看這句話」，優先改通用的步驟（拿掉客套話 → 判斷是問命／心情／聊天／世界上的事 → 找關鍵字 → 找主題），
   不要只為一個句型加規則；改完兩組題都要再跑一次。
