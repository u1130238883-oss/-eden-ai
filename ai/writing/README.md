# 寫作訓練：詳寫、擴寫、修改（2026-10-23）

## 題目（`gen.py`，500,000 題；`--holdout` 20,000 題沒看過的）

- **擴寫（中英西義）**：「擴寫：樹在成長」「Expand: The tree is growing.」「Amplía: El río fluye.」「Espandi: Il sole sta sorgendo.」
  主角 7 類（植物、動物、水、天空、人、東西、抽象）× 動作 8 類（成長、流動、飛舞、發光、凋零、聲音、靜止、變化），加上時間、地點、補充說明。
- **詳寫**：「小明哭了，請詳寫」——人物的情緒和動作（24 類）、景物（下雨、下雪、夕陽、夜晚）。
- **修改**：「幫我修改這段：小明哭了。小明很傷心。」
- **不是寫作**：「描寫是什麼意思」「小明哭了」「擴寫和縮寫有什麼不同」。
- 驗證題用沒看過的主角（楓樹、松鼠、燈塔）、動作（一點點褪色、照亮了大地）、人名（小芳、陳大文）、問法（「把X寫成一段優美的文字」）。

## 合格的標準（`Writer.review`，測試另外再獨立檢查一次）

| 要求 | 說明 |
|---|---|
| 字數 | 至少原句的 **9 倍**：中文算字（「樹在成長」4 字 → 至少 36 字），英西義算單字（4 個字 → 至少 36 個字） |
| 環境 | 天氣、光線、聲音、地點 |
| 感受 | 至少兩個不同的情感詞（我的心、感動、溫柔、heart、joy、corazón、cuore……） |
| 觀點 | 「我想」「我相信」「在我看來」「I believe」「Para mí」「Credo che」 |
| 比喻 | 彷彿、宛如、像、like、as if、como、come |
| 點題 | 中文用成語（成語庫裡的），英西義用諺語 |
| 層次 | 寫作至少 8 句（環境 → 主角 → 把原句寫活 → 比喻 → 感受 → 成語 → 觀點 → 收尾），修改至少 6 句 |
| 詳寫、修改 | 至少 3 個這一類的高級詞（哭：潸然淚下、哽咽、晶瑩……），不能有衝突的情緒（哭的時候不能「興高采烈」），不能留著「很傷心」這種平淡的詞 |
| 其他 | 要提到主角、不重複、英西義不能混進中文 |

## 怎麼寫：先寫第一稿 → 檢查 → 修改 → 再檢查

第一稿故意很平淡（「樹在成長。我覺得很好。」），檢查出問題後一次改兩項，直到沒有問題：
字數不夠 → 多寫細節；沒有環境 → 補環境烘托；沒有感受 → 寫心裡的感受；沒有觀點 → 加自己的看法；
沒有比喻 → 加比喻；沒有點題 → 用成語／諺語；用詞太平淡 → 把平淡的句子改寫成生動的描寫（「很傷心」→「黯然神傷」）。

| 2 | 79.12% | 72.92% | 「這讓**我想**起一句成語」被當成觀點（其實沒有自己的看法）→ 成語那句改成「正如一句成語所說」；情感詞的清單太窄（「我的心也跟著慢了下來」明明是感受）→ 擴充；寫不夠感受時可以再多寫幾句心裡的話；詳寫優先挑有高級詞的句子 |
| 3 | 92.67% | 89.80% | 「今天，小美很累」：主角前面有時間，開頭變成「小美，小美很累」→ 整句照用；「很孤單」直接抄進開頭 → 先換成高級的詞；西義的「Espandi, per favore:」「Amplía, por favor:」聽不懂 → 補上；抽象主題的環境（翻開舊相簿）不算環境 → 補上這類環境詞 |
| 4 | — | — | 詳寫只寫主角、沒有寫「我」的感受 → 每一類補上旁觀者的感受（「看著小明奔跑的身影，我的心也跟著熱血沸騰起來」）；「很悠閒」「很安靜」沒有對應的高級說法 → 補上；景物題的主角（「晚霞在流動」）沒寫進文章 → 寫進去 |

## 之後要加新的寫法時
1. 材料在 `lexicon.py`（詳寫）和 `expand.py`（擴寫，四種語言），改完跑 `python3 ai/writing/gen_swift.py ios/EchoCore/Sources/EchoCore/WritingData.swift`。
2. 每一句「感受」要有至少兩個情感詞（`expand.py` 的 MARK），西班牙文、義大利文的主角用陽性單數，句子裡不用形容詞配主角。
3. 跑 `NINESUN_WR_OUT=/tmp/w swift test -c release -Xswiftc -enable-testing --filter WriterTests`，看 `/tmp/w.*.txt` 錯的分組；
   想「一個會寫作文的人會怎麼改」，優先改通用的步驟（檢查 → 修改），不要只為一題加規則。
