# NineSun 的常識（ai/commonsense）

簡單的問題 NineSun 自己回答，不用上網：「鯨魚是魚嗎」「台灣最高的山」「母親節是幾月幾號」「白飯怎麼煮」「推薦一部電影」。

## 不是背答案，是讀懂問題再推出答案

資料是一筆一筆的**事實**，不是寫好的回答。回答的時候（`ios/EchoCore/Sources/EchoCore/Commonsense.swift`）：

1. **找出問的是哪個東西**：大貓熊、熊貓、貓熊是同一個；「老人與海」裡的「人」、「挪威的森林」裡的挪威、「曬太陽」裡的太陽、
   「發光」裡的「光」都不算（名字前後接的字要合理，單字的名字要獨立出現）。
2. **找出問它的什麼**：吃什麼、住哪、會不會、是不是、為什麼、有幾個、多高、首都……（`cues`）。
3. **從事實推出答案**：
   - 是不是：「鯨魚是魚嗎」→ 鯨魚屬於哺乳類，魚是另一類 → 不是，再用說明解釋；「冥王星是行星嗎」→ 不是＝行星 → 不是。
   - 會不會：「企鵝會飛嗎」→ 不會＝飛 → 不會，再接「為什麼不會飛」的解釋；「鴕鳥會飛嗎」→ 不會，不過牠會跑得很快。
   - 能不能吃：「狗可以吃巧克力嗎」→ 狗的食物裡寫著不能吃巧克力、巧克力的說明寫著原因。
   - 在事實裡找肯定或否定：「月亮會發光嗎」→ 關於月亮發光的解釋寫著「自己不會發光」→ 不會。
   - 反查：「誰寫了少年維特的煩惱」→ 從人物的代表作找到歌德；「東京是哪個國家的首都」→ 從首都找到日本。
   - 沒提到主角的為什麼：「為什麼會打哈欠」→ 在所有解釋裡找最吻合、而且明顯勝出的一個。
4. 推不出來就回傳 nil，交給上網查。

另外 `Everyday.swift` 用算的：現在幾點、明天星期幾、今天農曆幾號、今年什麼生肖、閏年、某天星期幾、離過年還有幾天、
節日的日期（國曆、農曆、第幾個星期幾、節氣）、單位換算、中文數字的計算（「兩千五加一千五」「一百塊打八折」）。

## 資料（data/）

| 檔案 | 內容 |
|---|---|
| countries.txt | 國家：首都、洲、語言、貨幣、補充（一行一國） |
| extra.txt | 補充到已有的東西上（縣市、州、人口、面積…） |
| animals.txt | 動物：分類、吃、住、會／不會、壽命、腳、說明、為什麼 |
| nature.txt | 宇宙、天氣、自然、人體、食物、飲料 |
| more.txt | 科學、環境、健康、地標、組織 |
| people.txt | 人物（年代、國籍、代表作、名言、NineSun 的看法）和發明 |
| festivals.txt | 節日：日期規則、吃什麼、習俗、由來 |
| superlatives.txt | 「最…的…」：範圍、形容詞、東西、答案、補充 |
| howto.txt | 怎麼做：步驟、提醒、看法、什麼時候要看醫生 |
| recommend.txt | 推薦：項目、首選和理由、反問 |
| views.txt | 比較題的看法（貓和狗哪個好養） |

每一筆 `@名|別名,別名|類別`，下面每行 `屬性=值`；`因:關鍵詞/關鍵詞=解釋` 是「為什麼」。
改完執行：

```
python3 ai/commonsense/gen_swift.py ios/EchoCore/Sources/EchoCore/CommonsenseData.swift
```

會檢查屬性名稱、不能用的字元、重複的名字。**事實要正確**：不確定的寫「大約」、寫出有爭議的地方（尼羅河和亞馬遜河哪個長）。

## 怎麼驗證

- `CommonsenseTests`：固定日期下的各種問法（問法刻意跟資料不一樣）、不該攔下來的問題（算命、心情、作品內容、時事）。
- `UnderstandingCorpusTests`：10,110 題理解題。本地回答時必須是在講問題問的那個東西（不能把「挪威的森林」當成挪威），否則算錯。
- 除錯：`NINESUN_SIMPLE=題目檔 …xctest EchoCoreTests.SimpleQuestionsProbeTests` 逐題印出回答。
