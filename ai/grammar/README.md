# 詞性＋仿寫訓練（2026-10-23）

## 題目（`gen.py`，500,000 篇小短文；`--holdout` 20,000 篇）

- 每篇 2～4 句，由 14 種句型（`lexicon.TEMPLATES`）和 17 小類的詞組成（動物、人、植物、地方、東西、自然；移動、聲音、休息、拿東西、
  自然現象、植物的動作；形容詞；方式副詞、程度副詞、時間頻率副詞、句首副詞）。
- 兩種問法：**分析詞性**（「找出這段話的名詞、動詞、形容詞、副詞：…」）、**仿寫**（「照這段話的結構仿寫一段：…」）。
- 仿寫的標準：詞性的順序完全一樣、功能詞（的、地、著、了、在、把、和…）一樣，每個內容詞都換成**同一小類**的別的詞（句子才通順）：
  「美麗的蝴蝶輕輕地飛翔。」→「碧綠的小貓大聲地游泳。」
- 驗證題用 **App 不認得的詞**（企鵝、銀杏、偶爾、晶瑩、牽牛花…）和沒看過的句型——要靠上下文判斷詞性。

## 不認得的詞，像人一樣判斷（`Grammar.tag`）

1. **最確定的線索先看**：後面是「地」→ 副詞；後面是「的」→ 形容詞；前面是「的」→ 名詞；後面是形容詞 → 副詞（「相當柔軟」）；
   前面是「很、非常」→ 形容詞；後面是「著、了、起來」或前面是「地」→ 動詞；前面是「著、把、在、和」→ 名詞；
   在「…裡／上」前面 → 名詞、後面 → 動詞；句首接逗號 → 副詞（「頓時，」）；句首 → 名詞（主角）。
2. **用判斷出來的鄰居一步一步推**：主角後面、動詞前面 → 副詞（「海豚**依然**徐徐地」）；
   主角＋兩個不認得的詞＋句號 → 副詞＋動詞（「斑馬**偶爾滑行**。」）；程度副詞後面接句號 → 形容詞（「極其晶瑩。」）。
3. **推不出來才看字的意思**：藍、瑩、嫩像形容詞；滾、爬、唱像動詞；極、相像程度副詞。
4. **斷詞**：不認得的字連在一起時，三個字、結尾像名詞（花、掌、鵝…）的先切出來（「牽牛花｜相當｜嬌嫩」）。
