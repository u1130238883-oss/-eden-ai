# 成語訓練（2026-10-23）

成語庫：`idioms.py`——387 個成語，每個有意思、英西義的對應說法（有對應的諺語就用諺語：一石二鳥 → kill two birds with one stone／
matar dos pájaros de un tiro／prendere due piccioni con una fava）、語氣（鼓勵、安慰、冷靜、祝福、幽默、批評……），
加上 105 組近義、250 對反義。`gen_swift.py` 產生 `IdiomData.swift`。

## 五組訓練題（`gen.py`，每組 500,000 題＋20,000 題沒看過的問法）

| 組 | 在練什麼 |
|---|---|
| understand | 看懂跟成語有關的話在問什麼：意思、用法、出處（上網查）、找某一類的成語（「形容開心的成語」）、用成語說自己的心情（「我最近心灰意冷」→ 難過）、用成語說自己的毛病（「我老是三心二意怎麼辦」→ 上網找「怎麼改善意志不堅定」）、近義、反義；不是成語的問題（「量子力學的意思」）不能亂認 |
| near | 成語的近義成語；兩個成語意思一不一樣（「坐井觀天和井底之蛙意思一樣嗎」→ 相近） |
| anti | 成語的反義成語；兩個成語是不是相反（「心平氣和跟火冒三丈意思相反嗎」→ 對） |
| translate | 成語 → 英西義（「一石二鳥用英文怎麼說」）；外文 → 成語（「kill two birds with one stone 的成語是什麼」）；外文 → 另一種外文（透過成語對照） |
| voice | 個性：405 種命盤（9×9×9＝729，年月互換是同一張盤 → 81＋324＝405 種不同的人），同一句話用不同的語氣回應，配一句語氣對的成語（難過時不說笑、不說教；生氣時勸冷靜；考上大學 → 金榜題名） |

## 錯在哪裡、怎麼教

- **連接詞在成語裡**：「心平氣和**和**火冒三丈」「大**同**小異**跟**天壤之別」「截然不**同**與……」被切錯 →
  每個「和／跟／與／同」的位置都切切看，兩邊都是成語庫裡的成語才算（`Idioms.twoIdioms`）。反義詞模組也一樣（「同意」「和平」）。
- **開頭的情境、結尾的客套話**：「考考你，」「我兒子問我」「老師上課說到」「…，快告訴我」「…，謝謝」被當成題目的一部分 →
  `Understanding.bare`／`contextOpeners`、`EchoEngine.tidy` 先拿掉。
- **詞庫沒有的成語被當成成語**：「量子力學的意思」變成查「量子力學 成語 意思」→ 詞庫沒有的四字詞交給一般的理解，不硬當成語。
- **只說一個成語**：「身心俱疲」是在說自己累了，不是問意思；「答非所問」是在抱怨 NineSun 答得不好。
- **翻譯的開頭**：「請問一下X翻成英文」「麻煩一下，X」「那X的義大利文」——客套話不是要翻的內容；但「那條毛巾」的「那」是內容
  （「那」後面接外文才是口頭禪）。
- **個性的語氣**：生病時的開口要有關心的字（休息、照顧），不能只講道理。
